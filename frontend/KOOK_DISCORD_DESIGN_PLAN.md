# 🎮 GameLink KOOK/Discord 风格三端开发计划

**创建日期**: 2025-11-16
**设计风格**: KOOK + Discord
**技术栈**: React 18 + TypeScript + Vite + Arco Design

---

## 📐 设计理念

### KOOK/Discord 核心特点

1. **三栏布局** (可选)
   - 左侧：导航栏 (Server List)
   - 中间：主内容区 (Main Content)
   - 右侧：成员/详情 (Member List/Details)

2. **暗色主题优先**
   - 深色背景 (#2f3136, #36393f)
   - 高对比度文字
   - 精致的悬停效果

3. **流畅的交互**
   - 平滑过渡动画
   - 即时反馈
   - 模态框/侧边栏弹出

4. **现代化组件**
   - 圆角卡片
   - 模糊背景
   - 渐变色按钮

```
┌─────────────────────────────────────────────────────────┐
│                      Header (可选)                       │
├────┬────────────────────────────────────────┬───────────┤
│    │                                        │           │
│ S  │          Main Content                  │  Members  │
│ e  │                                        │           │
│ r  │                                        │  or       │
│ v  │                                        │           │
│ e  │                                        │  Details  │
│ r  │                                        │           │
│ s  │                                        │           │
│    │                                        │           │
├────┴────────────────────────────────────────┴───────────┤
│                      Footer (可选)                       │
└─────────────────────────────────────────────────────────┘
```

#### 组件特点
- **左侧栏** (50-60px): 服务器/模块图标列表
- **中间区域**: 自适应宽度的主内容区
- **右侧栏** (240-280px): 成员列表或详情面板，可折叠

### 2. KOOK风格侧边栏布局 (KookLayout)

```
┌─────────────────────────────────────────────────────────┐
│                      Top Navigation                      │
├───────────┬─────────────────────────────────────────────┤
│           │                                              │
│  Channel  │          Main Content Area                   │
│  List     │                                              │
│           │                                              │
│  (200px)  │                                              │
│           │                                              │
└───────────┴─────────────────────────────────────────────┘
```

#### 组件特点
- **顶部栏**: Logo + 搜索 + 用户信息
- **左侧栏** (200-240px): 频道/功能列表

## 📱 响应式设计

### 断点系统
```less
@screen-xs: 480px;   // 手机
@screen-sm: 768px;   // 平板
@screen-md: 992px;   // 小屏桌面
@screen-lg: 1200px;  // 大屏桌面
@screen-xl: 1600px;  // 超大屏
```

### 响应式策略
- **手机** (<768px): 单栏布局，隐藏侧边栏，底部导航
- **平板** (768-992px): 双栏布局，可折叠侧边栏
- **桌面** (>992px): 三栏布局，完整功能

## 💡 技术要点

### 1. 主题切换
```typescript
// 使用 CSS Variables
const toggleTheme = () => {
  document.documentElement.setAttribute(
    'data-theme',
    theme === 'dark' ? 'light' : 'dark'
  );
};
```

### 2. 平滑过渡
```less
.element {
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
}
```

### 3. 悬停效果
```less
.card {
  &:hover {
    transform: translateY(-2px);
    box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2);
  }
}
```

### 4. 模糊背景
```less
.modal-backdrop {
  backdrop-filter: blur(8px);
  background-color: rgba(0, 0, 0, 0.6);
}
```
