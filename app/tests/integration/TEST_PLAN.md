## 二、端到端流程测试

### E2E-1: 用户注册登录流程

1. **新用户注册**
   - [ ] 发送验证码
   - [ ] 提交注册信息
   - [ ] 自动登录
   - [ ] 跳转到首页

2. **账号密码登录**
   - [ ] 输入手机号/邮箱 + 密码
   - [ ] 登录成功
   - [ ] Token 保存
   - [ ] 用户信息加载

3. **微信登录** (仅小程序)
   - [ ] 调用 wx.login
   - [ ] 获取 code
   - [ ] 后端换取 token
   - [ ] 登录成功

### E2E-2: 浏览陪玩师流程

1. **首页浏览**
   - [ ] Banner 轮播
   - [ ] 热门游戏显示
   - [ ] 推荐陪玩师显示

2. **陪玩师列表**
   - [ ] 加载列表
   - [ ] 搜索功能
   - [ ] 筛选功能 (游戏、段位、价格)
   - [ ] 分页加载

3. **陪玩师详情**
   - [ ] 加载详情
   - [ ] 查看服务
   - [ ] 查看评价
   - [ ] 收藏功能

### E2E-3: 下单流程

1. **创建订单**
   - [ ] 选择服务
   - [ ] 选择数量
   - [ ] 填写备注
   - [ ] 提交订单
   - [ ] 订单创建成功

2. **订单支付**
   - [ ] 跳转支付页面
   - [ ] 选择支付方式
   - [ ] 调起支付
   - [ ] 支付成功回调
   - [ ] 订单状态更新

3. **订单详情**
   - [ ] 查看订单状态
   - [ ] 查看进度
   - [ ] 联系陪玩师

### E2E-4: 陪玩师工作流程

1. **接单流程**
   - [ ] 查看可接订单
   - [ ] 接受订单
   - [ ] 开始服务
   - [ ] 完成服务

2. **服务管理**
   - [ ] 创建服务
   - [ ] 编辑服务
   - [ ] 上下架服务

3. **数据统计**
   - [ ] 今日统计
   - [ ] 收益统计
   - [ ] 评价管理

### E2E-5: 聊天流程

1. **聊天室**
   - [ ] 进入聊天室
   - [ ] WebSocket 连接
   - [ ] 发送文本消息
   - [ ] 发送图片
   - [ ] 消息实时接收
   - [ ] 未读数更新

### E2E-6: 评价流程

1. **提交评价**
   - [ ] 完成订单后评价
   - [ ] 选择星级
   - [ ] 填写内容
   - [ ] 上传图片
   - [ ] 提交成功

2. **查看评价**
   - [ ] 我的评价列表
   - [ ] 陪玩师评价列表
