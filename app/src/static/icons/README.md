# TabBar 图标说明

## 需要的图标文件

| 文件名 | 用途 | 尺寸建议 |
|--------|------|----------|
| `home.png` | 首页（未选中） | 81×81 px |
| `home-active.png` | 首页（选中） | 81×81 px |
| `player.png` | 陪玩（未选中） | 81×81 px |
| `player-active.png` | 陪玩（选中） | 81×81 px |
| `message.png` | 消息（未选中） | 81×81 px |
| `message-active.png` | 消息（选中） | 81×81 px |
| `profile.png` | 我的（未选中） | 81×81 px |
| `profile-active.png` | 我的（选中） | 81×81 px |

## 设计规范

- **格式**: PNG（透明背景）
- **尺寸**: 81×81 像素（3 倍图 @3x）
- **颜色**: 
  - 未选中：`#666666`
  - 选中：`#7ACC35`（主题绿）
- **风格**: 线性图标，2px 线宽

## 推荐图标来源

- [Iconify](https://iconify.design/)

- [Feather Icons](https://feathericons.com/)
