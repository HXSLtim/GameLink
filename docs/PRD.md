## 一、产品概述

### 1.1 产品定位

GameLink 是一款面向游戏玩家的**陪玩社交平台**，连接有陪玩需求的用户与提供陪玩服务的陪玩师，提供从下单、匹配、服务、评价到结算的完整闭环。

### 1.2 目标用户

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| 普通用户 | 游戏玩家，希望找陪玩提升游戏体验 | 快速找到合适的陪玩师、安全支付、服务保障 |
| 陪玩师 | 擅长游戏的服务提供者 | 接单赚钱、管理服务、查看收益 |
| 平台管理员 | 运营与管理人员 | 用户管理、订单监控、数据分析、内容审核 |

### 1.3 商业模式

- **服务佣金**：平台对每笔订单收取 15%-25% 佣金（三维度阶梯计算）
- **系统定价**：按游戏段位统一定价，单价 20-60+ 元/小时
- **增值服务**：VIP 会员、优惠券、充值赠送

## 二、功能架构

### 2.1 系统角色与权限

```
超级管理员（Super Admin）
├── 管理端全部功能
├── RBAC 权限配置
└── 系统配置

运营管理员（Admin）
├── 订单管理 / 争议处理
├── 用户管理 / 内容审核
├── 数据分析 / 结算管理
└── 受 RBAC 权限控制

陪玩师（Player）
├── 工作台 / 接单管理
├── 服务管理 / 排班设置
├── 收益查看 / 提现
└── 实名认证 / 段位认证

├── 浏览陪玩师 / 下单
├── 聊天 / 评价

```

## 三、非功能需求

### 3.1 性能

- API 响应时间 < 200ms（P95）
- WebSocket 消息延迟 < 100ms
- 支持 1000+ 并发 WebSocket 连接
- 分页列表 < 500ms

### 3.2 安全

- JWT Token 认证 + 自动刷新
- HMAC-SHA256 请求签名验证
- AES-256-CBC 请求体加密（生产环境）
- CSRF 防护（管理后台）
- 速率限制（全局 + 按接口）
- 敏感词过滤

### 3.3 可用性

- 支持暗色/亮色主题切换
- 响应式布局（移动端 + PC 端适配）
- 离线状态提示与网络恢复
- 全局 Toast / 错误边界 / 空状态

### 3.4 兼容性

- Web（移动端 + PC 端）
- iOS / Android App（后续独立规划）

## 四、数据模型（核心）

### 4.1 用户体系

- **User**：用户基础信息（手机号、昵称、头像、角色、VIP 等级）
- **Player**：陪玩师扩展信息（评分、接单数、认证状态、在线状态）
- **UserRole / Role / Permission**：RBAC 权限模型

### 4.2 订单体系

- **Order**：订单（用户、陪玩师、游戏、服务类型、金额、状态）
- **OrderGroup**：主订单（支持订单拆分与转单）
- **Payment**：支付记录（支付方式、状态、第三方交易号）
- **Review**：评价（评分、内容、标签、图片）

### 4.3 游戏与服务

- **Game / GameCategory**：游戏与分类
- **PlayerService / ServiceItem**：陪玩师服务与服务项
- **PlayerRank**：陪玩师段位认证

### 4.4 通讯

- **Chat**：聊天消息（文字/图片/语音/系统消息）
- **WebSocket**：实时通讯（消息推送、在线状态、系统通知）

### 4.5 财务

- **Wallet**：钱包（余额、冻结金额）
- **Commission**：佣金记录
- **Withdraw**：提现记录
- **Recharge**：充值记录

## 六、接口规范

- 基础路径：`/api/v1`
- 认证方式：Bearer Token（JWT）
- 响应格式：`{ success: boolean, code: number, message: string, data: T, pagination?: {...} }`
- 错误码：HTTP 状态码 + 业务错误码
- 分页：`page` + `pageSize`，响应含 `pagination`
- Swagger 文档：`/swagger/index.html`
