## 1. 产品概述

### 1.1 产品愿景

GameLink 是一个现代化的游戏陪玩服务平台，致力于为游戏玩家提供高质量的陪玩服务，同时为陪玩师提供稳定的收入来源和职业发展平台。

### 1.2 产品定位

- **目标市场**：中国游戏陪玩服务市场
- **核心价值**：智能匹配、安全交易、优质服务
- **差异化优势**：系统统一定价、三维度抽成体系、完善的争议处理机制

### 1.3 核心功能

| 功能 | 描述 |
|------|------|
| 智能订单分配 | 用户与陪玩师自动匹配，支持抢单池和客服分配两种模式 |
| 多角色系统 | 三层架构（用户/陪玩师/管理员）+ RBAC 权限控制 |
| 实时通信 | 基于 WebSocket 的即时消息，支持公共聊天室和订单群聊（不支持私聊） |
| 支付结算 | 完整支付流程，包括订单、退款和收益结算 |
| 数据监控 | 实时订单状态、收益统计和系统指标 |

### 1.4 商业模式

| 收入来源 | 说明 |
|----------|------|
| 平台抽成 | 15-25%（三维度计算） |
| 系统定价 | ¥20-60+/小时（按段位） |
| 认证费用 | 陪玩师入驻认证 |
| 推广服务 | 陪玩师推广曝光 |

#### 抽成计算三维度

| 维度 | 说明 | 优先级 |
|------|------|--------|
| 项目抽成 | 服务项目级别的基础抽成（默认 20%） | 基础 |
| 陪玩师个人抽成 | 特定陪玩师的专属抽成比例 | 覆盖项目抽成 |
| 上月排名抽成 | 根据上月排名的阶梯式抽成减免（激励机制） | 叠加减免 |

## 2. 市场分析

### 2.1 目标用户群体

- 年龄：18-35岁游戏玩家
- 主要游戏类型：MOBA、FPS、RPG、卡牌

### 2.2 差异化策略

1. **系统统一定价**：按段位定价，保证价格透明
2. **三维度抽成**：激励优质陪玩师，排名越高抽成越低
3. **完善的争议处理**：双客服机制，保障双方权益
4. **不支持私聊**：所有沟通在公共聊天室或订单群聊，保障交易安全

## 6. 业务流程

### 6.1 订单流程

```
用户下单 → 支付 → 等待接单 → 陪玩师接单 → 服务进行中 → 服务完成 → 用户评价
```

### 6.2 订单状态流转

```
pending → confirmed（支付成功）→ in_progress（接单）→ completed（完成）
    ↓           ↓                    ↓                    ↓
 canceled    canceled            disputed              refunded
```

### 6.3 收入结算流程

```
订单完成 → 收入进入冻结余额 → T+7 售后期 → 无争议 → 解冻到可用余额 → 可提现
```
