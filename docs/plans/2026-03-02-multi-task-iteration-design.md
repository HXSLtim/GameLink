# GameLink 多任务迭代计划设计

> **创建日期**: 2026-03-02
> **设计师**: Claude
> **状态**: 已批准

---

## 1. 概述

本设计旨在通过 Codex Agents 并行执行 GameLink 项目的剩余待办任务，目标是在2周内完成所有高优先级任务，达到生产环境就绪状态。

**核心策略**: 按阶段分批发送，每批次验收通过后进行下一批次

---

## 2. 架构设计

```
主分支 (main/dev) - 稳定，仅合并验收通过
         │
         ▼
  Codex Dispatcher (任务依赖分析 + Worktree 创建)
         │
    ┌────┴────┬────────┬────────┐
    ▼         ▼        ▼        ▼
 Agent 1   Agent 2  Agent 3  Agent N
 (隔离)    (隔离)   (隔离)   (隔离)
    │         │        │        │
    └────┬────┴────────┴────────┘
         ▼
    代码审查 + 冲突解决
         │
         ▼
    合并到主分支
```

## 3. 批次任务分配

### 批次1：功能完善（3天）

| Agent | 任务 | 交付物 | 验收标准 |
|-------|------|--------|----------|
| Agent 1 | T1-003 完善在线客服 | 消息持久化、客服分配算法、未读计数、离线推送 | 单元测试通过 + API文档 |
| Agent 2 | T4-001 用户端单元测试 | vitest测试套件 | 覆盖率60%+ |
| Agent 3 | TD-001 国际化支持 | i18n配置 + 中英文语言包 | 切换语言生效 |

### 批次2：第三方服务（5天）

| Agent | 任务 | 依赖凭证 | 交付物 |
|-------|------|----------|--------|
| Agent 1 | T2-001 微信支付 | 商户号、API密钥 | 支付接口 + 回调处理 |
| Agent 2 | T2-002 支付宝支付 | 商户号、应用密钥 | 支付接口 + 回调处理 |
| Agent 3 | T2-003 微信登录 | AppID、AppSecret | 授权登录接口 |
| Agent 4 | T2-004 短信服务 | API密钥 | 验证码发送 + 模板 |
| Agent 5 | T2-005 OSS上传 | AccessKey、Bucket | 文件上传接口 |

### 批次3：联调与测试（3天）

- T1-005 前后端联调测试（人工参与）
- T4-002 E2E测试（Playwright）

### 批次4：生产准备（4天）

- T3-001 生产环境配置检查
- T3-003 安全审计与加固
- T3-002 性能测试与优化
- T3-004 生产部署流程验证

---

## 4. 验收标准

### 批次验收
- 所有单元测试通过
- 代码审查通过（无 critical 问题）
- 无合并冲突
- 功能演示成功

### 生产就绪标准
- 安全审计通过（无高危漏洞）
- 性能测试达标（响应时间 < 200ms P95）
- 数据库备份策略就绪
- 回滚方案测试通过

---

## 5. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|-----|------|------|----------|
| 第三方凭证未就绪 | 中 | 高 | 提前准备，使用Mock开发 |
| 合并冲突 | 高 | 中 | 每批次及时合并，减少分支差异 |
| Agent 执行失败 | 中 | 中 | 设置超时，失败后手动接管 |
