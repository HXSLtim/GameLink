## 📐 设计系统

### 色彩系统 (Color Palette)

#### 深色主题 (Dark Theme) - 默认

```css
/* 主要颜色 */
--primary-bg: #36393f;          /* Discord经典深灰背景 */
--secondary-bg: #2f3136;        /* 卡片/面板背景 */
--tertiary-bg: #202225;         /* 侧边栏背景 */
```

## 🎯 组件设计规范

### 按钮 (Button)

```tsx
/* Primary Button - 主要操作 */

  立即下单
</Button>

- 文字色：#ffffff
- 圆角：--radius-md
- 高度：40px
- 内边距：12px 24px
- Hover：背景加亮 10%
- Active：缩放 0.95
```

```tsx
/* Secondary Button - 次要操作 */
<Button type="secondary">
  查看详情
</Button>

样式：
- 背景色：transparent
- 边框：1px solid var(--divider)
- 文字色：--text-primary
- Hover：背景 --hover-overlay
```

```tsx
/* Ghost Button - 幽灵按钮 */
<Button type="ghost">
  取消
</Button>

样式：
- 背景色：transparent
- 文字色：--text-secondary
- Hover：背景 --hover-overlay
```

### 头像 (Avatar)

```tsx
/* 带状态指示器 */
<Avatar
  src="avatar.jpg"
  size={48}
  status="online"  /* online | idle | dnd | offline */

- 圆形：border-radius: --radius-full
- 状态点：右下角，12x12，边框2px白色
- 在线：--status-online
- 忙碌：--status-idle
- 游戏中：--status-dnd
- 离线：--status-offline
```

## 🎭 交互设计

### 动画效果

```css
/* 页面切换 - Fade + Slide */
@keyframes page-enter {
  from {
    opacity: 0;
    transform: translateX(20px);
  }
  to {
    opacity: 1;
    transform: translateX(0);
  }
}

/* 卡片悬浮 */
.card:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-xl);
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 按钮点击 */
.button:active {
  transform: scale(0.95);
  transition: transform 0.1s;
}

/* 消息发送 - 滑入 */
@keyframes message-in {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 微交互

1. **状态切换**
   - 在线状态切换时，圆点闪烁
   - 新消息到达，红点弹跳

2. **加载状态**
   - Discord风格脉冲加载
   - 骨架屏渐现

3. **通知**
   - 右上角Toast通知
   - 3秒后自动消失
   - 支持堆叠显示
