## 🎯 开发优先级路线图

### Phase 1: 缺失功能补全 (2-3 周)

#### 1.1 用户端前端开发 (P1)
**目标**: 完成用户下单、支付、订单管理界面

```
user/                          # 用户端目录
├── src/
│   ├── pages/
│   │   ├── home/              # 首页
│   │   ├── games/              # 游戏列表/选择
│   │   ├── orders/              # 我的订单
│   │   │   ├── List.tsx        # 订单列表
│   │   │   ├── Detail.tsx       # 订单详情
│   │   │   └── Create.tsx       # 创建订单
│   │   ├── wallet/             # 钱包
│   │   │   ├── Recharge.tsx     # 充值
│   │   │   ├── Withdraw.tsx     # 提现
│   │   │   └── Records.tsx      # 交易记录
│   │   ├── profile/            # 个人中心
│   │   └── auth/               # 登录/注册
│   ├── components/
│   │   ├── GameCard.tsx         # 游戏卡片
│   │   ├── OrderTimeline.tsx     # 订单时间线
│   │   └── PaymentModal.tsx      # 支付弹窗
│   └── api/
│       ├── order.ts
│       ├── payment.ts
│       └── wallet.ts
```

**任务清单**:
- [ ] 搭建项目脚手架 (复用 admin 技术栈)
- [ ] 实现游戏选择和段位选择
- [ ] 实现订单创建流程
- [ ] 集成微信支付/支付宝
- [ ] 实现钱包充值/提现
- [ ] 订单状态实时更新 (WebSocket)
- [ ] 个人中心/订单历史

**负责人建议**: 1 名前端开发者
