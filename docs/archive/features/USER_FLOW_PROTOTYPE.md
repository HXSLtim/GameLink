## ⚡ 快捷操作

### 用户端

1. **快速下单**
   - 陪玩师卡片 → 点击"立即下单" → 跳过详情页直接下单

2. **快速联系**
   - 订单卡片 → 点击头像 → 直接打开聊天窗口

3. **快速筛选**
   - 陪玩师列表 → 点击标签 → 自动筛选

### 陪玩师端

1. **快速接单**
   - 工作台通知 → 点击"接单" → 一键接单

2. **批量操作**
   - 订单列表 → 长按 → 多选 → 批量完成/拒绝
