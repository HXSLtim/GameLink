## 设计原则

### 核心设计理念

```
┌─────────────────────────────────────────────────────────────┐
│  设计原则                                                    │
├─────────────────────────────────────────────────────────────┤
│  1. 简洁优先    最少步骤完成核心任务                          │
│  2. 角色清晰    用户端与陪玩师端明确区分                       │
│  3. 视觉统一    遵循品牌色系和组件规范                         │
│  4. 操作流畅    减少页面跳转，提升转化率                       │
│  5. 信息透明   关键信息（价格、评分）清晰展示                 │
└─────────────────────────────────────────────────────────────┘
```

### 品牌色彩规范

```
主色调:
├── 品牌色   #667eea  (紫色渐变主色)
├── 辅助色   #764ba2  (深紫色)
└── 强调色   #f59e0b  (橙色 - 用于价格、CTA)

功能色:
├── 成功     #10b981  (绿色)
├── 错误     #ef4444  (红色)
├── 警告     #f59e0b  (黄色)
└── 信息     #3b82f6  (蓝色)

中性色:
├── 正文     #1f2937  (深灰)
├── 副标题   #6b7280  (中灰)
├── 提示     #9ca3af  (浅灰)
└── 边框     #e5e7eb  (极浅灰)
```

## 交互规范

### 1. 点击反馈

```
• 所有可点击元素都有点击态
• 点击态：透明度降低至 0.7
• 按钮点击：轻微缩放效果 (0.98)
• 长按：震动反馈（如果支持）
```

### 2. 页面跳转

```
• 返回操作：右滑返回手势
• Tab 切换：底部标签直接切换
• 页面跳转：原生路由跳转
• 详情页：新页面打开（保留返回）
```

### 3. 表单交互

```
• 输入框：获取焦点时键盘自动弹出
• 选择器：底部弹出选择器
• 日期选择：底部弹出日期选择器
• 表单验证：实时验证，失去焦点时提示
```

### 4. 列表交互

```
• 下拉刷新：下拉刷新列表
• 上拉加载：上拉加载更多
• 侧滑操作：左滑显示操作按钮
• 长按操作：长按显示更多选项
```

### 5. 反馈提示

```
• 成功提示：顶部绿色 Toast
• 错误提示：顶部红色 Toast
• 加载提示：中心 Loading
• 确认弹窗：底部 Action Sheet
```

### 6. 动画效果

```
• 页面切换：淡入淡出 (300ms)

• 卡片展开：高度动画 (300ms)
```
