- [ ] 1.1.2 实现埋点数据处理流程
  - **实时数据处理流程:**
    - 前端埋点 SDK → 批量上报 API → 消息队列(Redis Stream/RabbitMQ)
    - 消费者服务:从队列读取数据 → 数据清洗 → 写入数据库
    - 实时统计:更新 Redis 缓存(在线用户数、实时 PV/UV)
  - **离线数据处理流程:**
    - 定时任务(每小时):聚合统计 → 写入 user_activity_stats 表
    - 定时任务(每天凌晨):计算留存率 → 写入 user_retention_data 表
    - 定时任务(每周):数据归档 → 迁移冷数据到归档表
  - **数据质量监控:**
    - 监控埋点数据上报成功率(目标 > 99%)
    - 监控数据处理延迟(目标 < 5 秒)
    - 监控异常数据占比(目标 < 1%)
    - 监控数据库查询性能(慢查询告警)
  - _需求: 9.2, 9.4_

    - 步骤 8:funnel_order_payment_submit - 提交支付(orderId, paymentMethod)
    - 步骤 9:funnel_order_payment_success - 支付成功(orderId, amount)
  - **用户注册转化漏斗:**
