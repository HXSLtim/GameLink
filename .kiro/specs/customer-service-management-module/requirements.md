# 客服管理与计费模块需求文档

## 简介

客服管理与计费模块是 GameLink 陪玩管理平台的客服支持系统,用于管理客服人员的工作量和薪酬计算。该模块支持两种灵活的计费模式:单量模式(按处理工单数量计费)和抽成模式(按订单金额抽成计费),帮助平台根据不同的业务场景和客服类型选择最合适的激励方式。

## 术语表

- **系统**: 指 GameLink 陪玩管理平台的客服管理与计费模块
- **管理员**: 具有配置客服计费规则和查看客服数据权限的平台管理人员
- **客服人员**: 负责处理用户咨询、投诉和问题的平台工作人员
- **工单**: 用户提交的咨询、投诉或问题处理请求
- **单量模式**: 按客服人员处理的工单数量计算薪酬的计费方式
- **抽成模式**: 按客服人员处理的订单金额抽取一定比例作为薪酬的计费方式
- **单价**: 在单量模式下,每处理一个工单的固定报酬金额
- **抽成比例**: 在抽成模式下,从订单金额中抽取的百分比
- **工单类型**: 工单的分类(咨询/投诉/售后/技术支持等)
- **处理时长**: 客服人员从接收工单到完成处理的时间
- **客服绩效**: 基于工单处理数量、质量和用户满意度的综合评估
- **计费周期**: 用于计算客服薪酬的时间周期(日/周/月)

## 需求

### 需求 1

**用户故事:** 作为管理员,我希望为客服人员配置计费模式,以便根据不同岗位选择合适的薪酬计算方式。

#### 验收标准

1. WHEN 管理员创建客服账号 THEN 系统应支持选择单量模式或抽成模式作为计费方式
2. WHEN 管理员选择单量模式 THEN 系统应要求设置每个工单的单价金额
3. WHEN 管理员选择抽成模式 THEN 系统应要求设置抽成比例百分比
4. WHEN 管理员修改计费模式 THEN 系统应记录修改历史和生效时间
5. WHEN 管理员查看客服列表 THEN 系统应展示每个客服的计费模式和费率

### 需求 2

**用户故事:** 作为管理员,我希望按工单类型设置不同的单价,以便对复杂工单给予更高报酬。

#### 验收标准

1. WHEN 管理员配置单量模式 THEN 系统应支持为不同工单类型设置不同的单价
2. WHEN 管理员创建工单类型 THEN 系统应要求设置该类型的默认单价
3. WHEN 客服处理工单 THEN 系统应根据工单类型自动应用对应的单价
4. WHEN 管理员修改工单单价 THEN 系统应立即应用到后续处理的工单
5. WHEN 管理员查看单价配置 THEN 系统应展示所有工单类型及其单价

### 需求 3

**用户故事:** 作为管理员,我希望统计客服的工单处理量,以便计算单量模式下的薪酬。

#### 验收标准

1. WHEN 客服完成工单处理 THEN 系统应记录该工单的处理时间和工单类型
2. WHEN 管理员查看工单统计 THEN 系统应展示客服在指定周期内处理的工单数量
3. WHEN 系统计算单量薪酬 THEN 系统应累加所有已完成工单的单价总和
4. WHEN 管理员筛选统计数据 THEN 系统应支持按客服、时间范围、工单类型筛选
5. WHEN 管理员导出统计 THEN 系统应支持导出工单处理统计为 Excel 格式

### 需求 4

**用户故事:** 作为管理员,我希望追踪客服处理的订单金额,以便计算抽成模式下的薪酬。

#### 验收标准

1. WHEN 客服处理订单相关工单 THEN 系统应记录该工单关联的订单金额
2. WHEN 管理员查看订单统计 THEN 系统应展示客服在指定周期内处理的订单总金额
3. WHEN 系统计算抽成薪酬 THEN 系统应将订单总金额乘以客服的抽成比例
4. WHEN 工单未关联订单 THEN 系统应标记该工单不计入抽成薪酬计算
5. WHEN 管理员查看抽成详情 THEN 系统应展示每个订单的金额和抽成金额

### 需求 5

**用户故事:** 作为管理员,我希望生成客服薪酬报表,以便进行薪酬结算和审核。

#### 验收标准

1. WHEN 管理员生成薪酬报表 THEN 系统应支持选择计费周期和客服人员
2. WHEN 系统生成报表内容 THEN 系统应包含工单数量、订单金额和应付薪酬
3. WHEN 客服使用单量模式 THEN 报表应展示各类型工单数量和对应单价
4. WHEN 客服使用抽成模式 THEN 报表应展示订单总金额和抽成比例
5. WHEN 管理员导出报表 THEN 系统应支持导出 PDF 和 Excel 格式

### 需求 6

**用户故事:** 作为管理员,我希望查看客服的工作绩效,以便评估客服的工作质量。

#### 验收标准

1. WHEN 管理员查看客服绩效 THEN 系统应展示工单处理数量、平均处理时长和用户满意度
2. WHEN 系统计算满意度 THEN 系统应基于用户对客服服务的评价计算平均分
3. WHEN 管理员查看绩效趋势 THEN 系统应展示最近 30 天的绩效变化曲线
4. WHEN 管理员对比客服 THEN 系统应支持按绩效指标对客服进行排序
5. WHEN 绩效低于阈值 THEN 系统应标记该客服为需要关注对象

### 需求 7

**用户故事:** 作为管理员,我希望设置客服的工作时段,以便合理安排客服排班和计算工作时长。

#### 验收标准

1. WHEN 管理员配置工作时段 THEN 系统应支持设置客服的上班时间和下班时间
2. WHEN 客服登录系统 THEN 系统应记录登录时间作为上班打卡
3. WHEN 客服退出系统 THEN 系统应记录退出时间作为下班打卡
4. WHEN 管理员查看工作时长 THEN 系统应展示客服的实际工作时长和应工作时长
5. WHEN 工作时长不足 THEN 系统应标记为异常并通知管理员

### 需求 8

**用户故事:** 作为管理员,我希望设置客服的薪酬保底,以便保障客服的基本收入。

#### 验收标准

1. WHEN 管理员配置薪酬保底 THEN 系统应支持设置客服的最低月薪金额
2. WHEN 系统计算薪酬 THEN 系统应比较实际薪酬和保底薪酬
3. WHEN 实际薪酬低于保底 THEN 系统应按保底薪酬发放并标记为保底发放
4. WHEN 实际薪酬高于保底 THEN 系统应按实际薪酬发放
5. WHEN 管理员查看薪酬明细 THEN 系统应展示实际薪酬、保底薪酬和最终发放金额

### 需求 9

**用户故事:** 作为管理员,我希望查看客服的薪酬历史,以便审计和分析薪酬数据。

#### 验收标准

1. WHEN 管理员查看薪酬历史 THEN 系统应展示每个计费周期的薪酬记录
2. WHEN 管理员筛选记录 THEN 系统应支持按客服、时间范围、计费模式筛选
3. WHEN 管理员查看统计 THEN 系统应展示总薪酬支出和平均薪酬
4. WHEN 薪酬结算完成 THEN 系统应记录该周期的薪酬详情到历史记录
5. WHEN 管理员导出历史 THEN 系统应支持导出薪酬历史记录为 Excel 格式

### 需求 10

**用户故事:** 作为管理员,我希望设置客服的绩效奖金,以便激励优秀客服提升服务质量。

#### 验收标准

1. WHEN 管理员配置绩效奖金 THEN 系统应支持设置奖金规则和触发条件
2. WHEN 客服满足奖金条件 THEN 系统应自动计算奖金金额并加入薪酬
3. WHEN 管理员查看奖金记录 THEN 系统应展示每个客服获得的奖金和原因
4. WHEN 奖金规则修改 THEN 系统应立即应用到后续的薪酬计算
5. WHEN 管理员生成奖金报表 THEN 系统应支持导出绩效奖金统计报表
